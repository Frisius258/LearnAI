## 智能的两大流派

### 1. 符号主义（Symbolicism）

**从符号和规则计算出推理和思考**

- 典例：专家系统（Expert System）
- 核心思想：建立一套形式体系，用逻辑来刻画世界
  - 例如：a∧b → c（逻辑蕴含，logical entailment）
- 致命缺陷：
  - 现实世界没有清晰直接的规则
  - 完全复制人类经验，无法提升自身水平
  - 能力上限是人类专家水平

### 2. 机器学习 / 联结主义（Connectionism）

**通过引导和学习，让其在某任务上表现的越来越好**

- `奖励` 与 `惩罚` 机制(反射)
- 自我调整
- 核心思想：规则不是人写的，是从数据中学出来的

#### 一个区分符号主义和联结主义的例子

人类概念的产生是基于概念的组合，而多层网络可以形成新的概念复合。这让我们联想到文本解析器的一种特点：

**上下文无关文法（Context-Free Grammar, CFG）**

比如对于一个只有＋ * 的表达式，我们的理解：
- 最底层是 digit = 0|1|2|...|9
- 然后一层是 factor 的最小单位：factor :: digit | '(' Expr ')'
- 然后是 * 的组合单位：term :: factor (* term | ε) 
  - 就是 * 的两侧要么是 factor 本身，要么是 factor * 后面还有东西

总而言之，这个语言很抽象，但是总归而言很类似多层感知机逐层组合实现的东西——每一层都在上一层的基础上构建更复杂的特征（hierarchical feature learning）

举个例子，对于解析图片中人手写的数字：
- 我们先在第一层感知机对图像做简单的笔画判断
- 然后第二层用第一层的信息拟合出圈之类的结构
- 最后一层再组合出我们想要的识别结果

**但是，CFG 和 MLP 虽然都有"层次结构"，却走了完全不同的路：**

| 维度 | CFG（符号主义路径） | 神经网络（联结主义路径） |
|------|---------------------|-------------------------|
| **规则来源** | 人手工写的，确定性的 | 从数据中学出来的 |
| **表示方式** | 离散符号 | 分布式向量表示（distributed representation） |
| **中间结构** | 有明确的语法含义（factor 就是"因子"，term 就是"项"） | 单个神经元的激活没有清晰的语法含义——意义编码在整个层的激活模式里 |
| **本质** | 显式的、可解释的层次分解 | 隐式的、统计性的特征学习（黑盒） |

所以更准确的说法是：
- CFG 的层次结构是"人为设计的语法树"
- 神经网络的层次结构是"从数据中自动涌现的特征层级"

而我们想到的，只是它们恰好都具有"可以分层"的效果。

### 1. 怎么搭建有学习能力的黑箱？

> 联结主义(Connectionism)：通过仿生的方式, 模拟单个神经元的复杂功能以及神经元之间的复杂连接

*与符号主义同源*

**搭建黑箱：** 使用一系列的属性(所有特征)描述事物, 用1表示符合, 0表示不符合

符合特征乘正系数, 不符合乘负系数, 求和获得评分, **设置得分阈值，高于阈值时激活感知机**

- **感知机（Perceptron）：** $y = \sum_{i=1}^{n}w_ix_i - b$
  - w 权重（weight）
  - x 输入特征（可以是连续值，也可以离散）
  - b 偏置（bias）
  - 输出对应二分类（1/0），表示神经元有没有被激活
- 最早期借鉴脱胎于符号主义
- 与神经科学不谋而合
  - 通过电信号传递信息, 树突（dendrite）接受, 轴突（axon）传递
  - 可能通过输入抑制或激活神经元活动, 神经元直接叠加所有刺激的影响
  - 《神经活动中内在的逻辑演算》（A Logical Calculus of the Ideas Immanent in Nervous Activity, McCulloch & Pitts, 1943）

**模式识别：** 从输入数据中识别不同特征的模式，理解概念的过程

- 计算机视觉: 通过对数字组成的矩阵纯粹的计算, 得出答案(照片里的是男人?是女人?)

>人类对于自己不了解的东西很容易浪漫, 也很容易对未来过分乐观！

#### 怎么搭建黑箱(例如感知机等模型)?

**联结主义的信念：**

通过设计某套参数, 使模型设计足够强大，**任何想要实现的功能本质上都可以通过设定某套参数实现**

- 反对: "机械模拟", "结构太简单"
- 致命弱点: 感知机无法完成 <span style="color:red">XOR</span>!

| x | y | x XOR y |
|---|---|---------|
| 0 | 0 | <span style="color:lime">0</span> |
| 0 | 1 | <span style="color:lime">1</span> |
| 1 | 0 | <span style="color:lime">1</span> |
| 1 | 1 | <span style="color:lime">0</span> |

- 将所有 $x, y$ 输入画在二维平面上，感知机能做到的仅仅是**线性规划问题**，满足激活和不激活的分界线永远是一条直线
- ![image01](./image/01.png)
- 如图所示，**不可能存在一条直线让这样的激活成立**
- 这是 Minsky 在 1969 年指出的理论局限性：单层感知机无法解决线性不可分问题

> 人类又是这么悲观, 一个小小的反例就自暴自弃, 放弃了充满潜力的研究方向！

最后坚持下来的那批人, 终于守得云开见月明, 成为了我们如今深度学习的奠基人

#### 多层感知机（MLP, Multi-Layer Perceptron）

对于 XOR，我们考虑**多层嵌套感知机**，前一层的感知机输出作为下一层感知机的输入

- ![image02](./image/02.png)
- x 只在 (1, 0) 激活 ($1x + (-1)y > 0.5$)
- y 只在 (0, 1) 激活 ($(-1)x + 1y > 0.5$)
- 分别关注我们想激活的位置, 将神经元的输出相加
- 每一根连线代表神经元之间的连接强度（即权重 weight）

*大名鼎鼎的神经网络中最经典、最基础的一种*

![image03](./image/03.png)

#### MLP vs CNN：不同的"积木"

**MLP 的局限：**

MLP 会对上一层的所有感知机（神经元）建立连接，那就是将所有信息展平成一个一维的向量，此时可以认为原本具有局部信息的空间结构被抹杀。

就比如对于一个图像，我想在局部看它是不是一个圈，肯定在局部的像素点看比全局看更明显。

- MLP 的基本积木是**感知机（神经元）**
- 手写数字识别那个例子，"第一层学笔画、第二层学圈、第三层学数字"，这其实更准确地描述的是 CNN

**CNN（卷积神经网络, Convolutional Neural Network）：**

视觉系统中，神经系统的神经元不需要和前一层的所有神经元全部稠密连接，只需要和**局部神经元连接**即可，并且每层神经元连接的结构是类似的

借鉴这一点而**减少计算量、提高性能**，设计出了 CNN

- CNN 的基本积木是**卷积核（filter/kernel）**——一个小矩阵在图像上滑动
- CNN 通过卷积核保留了空间结构
- 对于同一个层与层之间的连接采用**相同的参数**（参数共享，parameter sharing），但保证的是局部相连接
- 所以能自然地学到从局部到整体的视觉特征层级

![image04](./image/04.png)

#### 深度学习的重要课题：如何设计更好更强大的模型结构？

**残差网络（ResNet, Residual Network）**

当层数越来越多的时候存在两个问题：
1. **梯度爆炸/消失（vanishing/exploding gradients）**：参数不断规约向后传递时信息的残余量极少
2. **退化问题（degradation problem）**：出现较大偏差结果，不是过拟合的问题，是数据本身规约到这里有的问题

此时，我们产生一个思想：

**两个问题的差距很大，对于学习而言，建立"怎么从 a 到 b"，是远远难于"分辨 (a,b) 的差距"**

所以：
- 原先对于一层的要求是 x → f(x)（机器通过自发调整参数来实现一个生成的过程，从 a 到一个近似 b 的东西）
- 现在试图找一个函数 x → g(x)，其中 g(x) = f(x) - x
- 那么 x → f(x) ≡ x → (f(x) - x) + x ≡ x → g(x) + x
- 这里认为我们要去学习的是 a、b 之间的**不同**（残差）

**跳跃连接（Skip Connection）：**

```
输入 x
  │
  ├──── 跳跃（shortcut）────┐
  │                         │
  ▼                         │
[F(x)]  ← 正常处理           │
  │                         │
  ▼                         ▼
  输出 = F(x) + x  ← 把跳跃加回来
```

- 每一层都有一条"捷径"，让输入 x **不经过任何变换**直接传到输出端
- 层还是要走，但层只需要学"额外要改变的部分" F(x)，而不是完整的 H(x)
- 如果某层"没什么可学的"，F(x) ≈ 0，输出 ≈ 输入，至少不会变差

**为什么有效？**

1. **梯度高速公路**：反向传播时，梯度可以通过跳跃连接直接回传，不会在层层传递中消失
   - ∂(F(x) + x)/∂x = ∂F(x)/∂x + **1**，这个 1 保证梯度至少不会消失
2. **学残差比学完整映射容易**：让 F(x) 逼近 0 比让一整层直接逼近 H(x) 简单
3. **缓解退化问题**：深层网络至少不差于浅层网络（因为多余的层可以学 F(x) = 0）

**DenseNet（密集连接网络, Densely Connected Convolutional Network）**

将任意两层都跳跃连接起来，每一层接收**所有前面层**的输出：

```
层0 输出: x₀
层1 输出: x₁ = F₁([x₀])           ← 接收 x₀
层2 输出: x₂ = F₂([x₀, x₁])       ← 接收 x₀ 和 x₁
层3 输出: x₃ = F₃([x₀, x₁, x₂])   ← 接收 x₀、x₁、x₂
```

**[x₀, x₁, x₂]** 表示把这些特征**拼接（concatenate）**在一起，不是相加。

**ResNet vs DenseNet 的信息流方式：**

| 网络 | 输入到 F 的内容 | 输出 |
|------|----------------|------|
| ResNet | 只有前一层 x₁ | F(x₁) + x₁ |
| DenseNet | [x₀, x₁, ...] 拼接 | F([x₀, x₁, ...]) |

- ResNet 是"函数外相加"，DenseNet 是"函数内拼接"
- DenseNet 比 ResNet 更不容易梯度消失，因为任意两层之间都有直接连接，梯度路径更短
- 但通道数会爆炸，需要用**压缩层（Transition Layer）**控制维度

**Transformer（Attention）：** 本质上也是某种网络的基本结构

#### 神经网络结构设计的学问

总而言之，我们需要设计出更好的类似神经元的"基"和组合积的方式"骨架"，此时这个设计会影响我们需要的数据量。

都是某种网络的基础框架结构，然后有大量参数要决定：
- **骨架（Architecture）** = 网络结构（多少层、怎么连接、用什么操作）
- **参数（Parameters）** = 权重、偏置等需要通过训练学习的数值

不同架构有不同的基本积木：
- MLP 的积木是**神经元**
- CNN 的积木是**卷积核**
- Transformer 的积木是**注意力头 + 前馈网络**

深度学习非常重要的领域：**神经网络结构设计**

通过**数据训练**发现蕴藏的结构，理解概念

### 2. 究竟如何奖励和惩罚一个神经网络?

各种人工智能无一例外都在使用**梯度下降**算法训练网络，来找到最好的参数

#### 梯度下降（Gradient Descent）

回顾 智能的本质就是从一堆点中找到一个拟合他们的关系的函数

线性组合一个 $(C, x, x^2, x^3, ...)$, 用多项式函数拟合
此时有 $y(x) = k_0 + k_1x + k_2x^2 + k_3x^3 + k_4x^4 + k_5x^5$

**损失函数：** 用一种定量的方式度量一组系数所对应的多项式到底拟合得好不好

衡量一个模型的预测和真实结果之间的**偏差程度**

这里有两种函数:

1. **拟合函数**
2. **损失函数**(计算真实结果与拟合函数的预计值之间的残差平方和)

**目的：** 找到最出色的 parameters：$\{k_0, k_1, k_2, k_3, k_4, k_5\}$

> 中学: 最小二乘法

这样，训练神经网络就成为了一个**通过调节参数旋钮来降低损失函数的游戏**

数学上处理这个问题叫做**非凸优化**，求解它的难度是臭名昭著的大

**梯度下降 + 反向传播**

我们首先只考虑其中一个参数k, 假设其他参数已经调节到最优
我们能得到的信息只有函数上离散的点
但是我们还可以知道这些离散的点的导数

**梯度下降的精神：**

- **每次减小一点点：** 每次减小损失函数，我们现在的位置应该往哪边走，然后往这个方向走一个很小的距离，这样我们就可以不断缩小损失函数，直到停在底部，参数基本不再变化
- 同时调节两个参数$k_1$, $k_2$时, 损失函数变成输入是两个实数, 输出是一个实数的二元函数, 可以表示成一个二维曲面
- **偏导数：** 固定其一只调节另一个
- **梯度**(本质上是一个 n 维向量)：把两个偏导拼成的列向量(二维版本的求导)，在某个给定位置函数值变化最快的方向(曲面在局部最陡峭的方向)
- 梯度给出了二维曲面上每个点**上升最快的方向**，梯度下降法就是反其道而行之

![image05](./image/05.png)

- 类似的，我们沿着梯度下降的方向每次调整一点点就可以减小损失函数
- 这启发我们任意个参数都可以这样做
- 对于我们的5个参数的函数，损失函数是一个六维曲面

因此，我们需要分别对每个参数求偏导，**组合成一个梯度，找到梯度下降的方向**。

<details>
<summary>$\nabla$算子介绍</summary>

>$\nabla$ 叫 **nabla 算子**，也叫**向量微分算子**
即 $∇ = (\frac{\partial}{\partial x_1},\frac{\partial}{\partial x_2},\frac{\partial}{\partial x_3},...)^T$
> - 作用于标量函数(标量场$f:\mathbb R^n\to \mathbb R$)可得 **梯度(gradient)**
> \[\nabla f = \left(\frac{\partial f}{\partial x_1},\frac{\partial f}{\partial x_2},\frac{\partial f}{\partial x_3},...\right)\]
> - 与向量场($\mathbf F:\mathbb R^n\to \mathbb R^n$)点乘可得 **散度(divergence)**
>\[\mathbf F = (F_1, F_2, F_3, ...)\]
其中每个$F_i$是$x_1, ..., x_n$的函数
\[\nabla\cdot\mathbf{F} = \frac{\partial F_1}{\partial x_1} + \frac{\partial F_2}{\partial x_2} + \cdots + \frac{\partial F_n}{\partial x_n}\]
> - 与向量场叉乘可得 **旋度(curl)**
> \(\nabla\times\mathbf F\)

</details>

> [!TIP]
> **梯度下降法可以优化网络，找到损失函数比较低的参数**

**梯度下降的局限性：**

梯度下降（如同蒙眼下山），是局部最优的一个**贪心算法**，具有局限性：
- 通常只会找到一个坑而不能再下降（局部最优）
- 可能卡在鞍点（saddle point）或平坦地带（plateau）

关于这个的优化，我们会引入：
- **动量（Momentum）**：累积之前的"速度"，像滚雪球一样冲过平坦区域或浅坑
- **多次随机初始化**：不同起点可能掉进不同的"坑"，挑最浅的
- **自适应学习率（Adam, RMSprop）**：更智能地调整步长

> [!NOTE]
> 这里我们将损失函数视作一个多维度的曲面，而在这个曲面上存在类似于坑和鞍的存在
> 
> 很多时候我们不需要最优的拟合，我们需要的是一个**足够好的拟合**（存在过拟合的问题），这个拟合具有很好的**泛化能力**

对于一个非常复杂的网络，我们如何计算这个梯度？

<span style="color:lime;font-size:20px"><b>反向传播(back propagation)</b></span>

**反向传播：** 专门用于计算复杂神经网络梯度的算法，是**很多人学习深度学习被劝退的第一步**

**最精髓的思想：** 神经网络本质上是用最基础的运算组合、复合、迭代而形成超级复杂的函数(由基础的积木拼接成的庞大机器)，我们只关心每个调节参数的旋钮的梯度(动一点点，损失函数随之变化的关系)，而这个信息是可以**由后向前层层传递**的

**导数的链式法则：**

$\dfrac{\partial f(g(x))}{\partial x} = f'(g(x))g'(x)$

![image06](./image/06.png)

> [!NOTE]
>三个齿轮转过的角度分别代表x, g(x), f(g(x))
g'(x)表示第二个齿轮g(x)相较于第一个齿轮x传动的速度之比
f'(g(x))表示第三个齿轮相较于第二个齿轮g(x)传动的速度之比
如果想直到变动一点点第一个齿轮, 第三个齿轮变化的速度会有多快, 我们就只需要把这两个齿轮的传动比相乘

有了链式法则，我们就可以**从后往前一步步拆解，得到每个参数的导数**。

![image07](./image/07.png)

(这里每层的偏导标注有误，应该是**后一层对前一层的偏导**)
从图片考虑, 损失函数就是参数经过多层函数复合后得到的输出

要求最初始的导数，我们就可以一层一层将每层之间的偏导从后往前相乘
这个算法就叫做**反向传播算法**

**反向传播的两遍计算：**

1. **前向传播（Forward Pass）**：从输入到损失，算"当前预测有多差"
   ```
   x → h = w₁·x → ŷ = w₂·h → L = Loss(ŷ, y)
   ```
2. **反向传播（Backward Pass）**：从损失到参数，算"每个参数该往哪调"
   ```
   ∂L/∂w₂ = ∂L/∂ŷ · ∂ŷ/∂w₂
   ∂L/∂w₁ = ∂L/∂ŷ · ∂ŷ/∂h · ∂h/∂w₁
   ```

→ 前向传播是**评估**，反向传播是**求导**，两遍计算**不同的东西**。

### 泛化(Generalization)

**推广、举一反三、活学活用**

最简单的泛化：将关联的趋势理解并且推广到**我们没有见过的一些输入数值**，通过理解底层规律，在未知的情景下给出合理的预测和输出
零散的数据点勾勒出了一种趋势，当我们用一个**连续平滑的函数**准确刻画出这种趋势之后, 就可以利用这个函数, 推测出数据中我们**没有见过的某一个输入下**, 对应合理的输出大概是多少

现实中的泛化往往非常抽象，不如曲线拟合这么直观
这正是神经网络强大的地方：**你只需要提供数据，底层抽象的趋势和规律交给神经网络自己学习**

不同情境中类似的有一种感觉和规律，难以用简单清晰的数学来计算和描述

**例：**

- 围棋？味道不好。
- 说话？一句话前面的语境下，后面应该接上一个什么样的话
- ![08](./image/08.png)
- 从氨基酸序列里分析出整个蛋白质的结构？(诺奖)

### 为什么深度学习强？

你只需要找一个**架构合适的神经网络**，收集数据，训练拟合，然后这个神经网络就会领会数据当中你所描述的输入和输出间微妙的联系，并举一反三，运用到它没有见过的情景输入中。

### 神经网络、深度学习是万能的吗？

尽管深度学习模仿了人类大脑的结构，但是它和真正的人类智能还有很大的区别。
因为神经网络对概念的**相关性和因果性没有把握**：这是收集数据、训练模型的这一套方法论中永远无法避免的。

**对抗样本：** 在人眼中看起来是杂乱无章的噪声，但是会导致神经网络将其看成与某些其他特定事物相同的样本

# 图片生成

### 扩散模型 Diffusion

墨水散开: 

- 数学：维纳过程 Wiener Process
- 物理：布朗运动 

**高斯分布：** 通过足够长时间的扩散，最终变成看似杂乱无章的一团的分布

>[!TIP]
>其实，这就是概率论中的一个经典结论**中心极限定理 CLT**

物理中研究扩散过程的物理学叫做**朗之万动力学(Langevin Dynamics)**

中心点扩散：对于一个小区域，倒退一段时间，这个区域的粒子会更接近中心点

**正向的扩散：** 机械无脑的热力学过程，无论是什么时候，它下一个时刻的去向都杂乱无章，均匀地向周围渐渐摊开

**反向的扩散：** 从一团混乱的高斯分布中重建出原有的结构(熵减：从混乱变得有秩序，是一个有信息、有方向的过程)

于是，在任何一个时刻t，我们都可以给空间上的每一个位置画出一个向量箭头，表示这个时刻的粒子在$\delta t$时间之前，平均应该在哪
而这样的向量场有一个名字，就叫做**评分函数 score function**

**评分函数(score function)：** 越来越接近粒子最初始位置的导航

![image09](./image/09.png)

**数学上一张图片看起来不是乱来的意味着什么？**

把图片像素每个RGB写下来组成一长串数字的列表，相邻的数字表示图片上相邻的像素
我们可以把每个数字当成一个坐标，于是一张图片就变成了一个向量，这些向量所在的空间叫做**像素空间**

任取像素空间的一个向量，把它的坐标一一转化成颜色，把它翻译成一张照片
这个空间极大部分向量组成的图像都是无意义的，只有极少部分看起来有意义

自然的一张图片通常是由色块组成
**色块**指的是大部分情况下，一个像素相邻区域的像素颜色类似(对像素的数值构建了约束)

除此之外，一张图片要像真的还要有**结构、透视、色彩、光影**等要素

在 AI 的视角下，这些有意义的图片就像在高维空间中一条**金色的矿脉**。

真正重要的是**这条矿脉在高维空间的结构**是什么样的。
这在计算机科学里是一个非常重要的观点，被称为**流形假设(Manifold hypothesis)**

真实图片的生成过程：从这个空间的任何一个位置走到这个流形上的一个点

怎样知道这个评分函数？

- 把输入定义成某个时刻粒子的位置，把输出规定为上一个时刻它的位置
这样**训练神经网络**，本质上就是学习这个**评分函数**

**去噪模型(Denoising Model)：** U-Net 沿着评分函数在空间中一点点移动，在像素空间中会越来越接近真实图片流形的那条矿脉
